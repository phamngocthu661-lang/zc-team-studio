# SCRIPT LANGUAGE + 50-MIN RETENTION MANUAL

## Documentary tone
Write directly to curious adult Spanish-Mexican audience (25–65+), with serious but accessible diction. Be compassionate even while addressing public scandals, never fictionalize on-camera revelations. Turn hard facts into engaging narrative through order and interpretation, not invented tension.

Pattern within every factual chapter: `event -> prior expectation -> documented complication -> alternate perspective -> consequence -> bridge`. Sensory description only when literally observable (recorded venue, published photo, performance footage); no unverifiable private room smells, exact emotions inside minds, whispered dialogue.

Hook examples are templates, not facts: `Durante años, [persona] fue sinónimo de [obra pública]. Pero [fecha/fuente] dejó constancia de [hecho verificable]. ¿Cómo llegó hasta ese punto, y qué cambió después?`

Narrative rhythm: 40–70 sec micro question/answer if meaningful, 5–7 minute macro documentary transition, 2–3 important source-backed payoffs. Avoid repetitive "pero lo peor aún no llegaba" and false omniscience. A public interview can be compelling if you contextualize why the timing mattered.

Spanish QA hotspots: accentuation (más/mas, él/el, sí/si, aún/aun), interrogatives (qué/como/cuándo), proper-name orthography (José María, Álvarez, Miguel etc), agreement and conjugation, punctuation with `¿?`, `¡!`, dates and quotes. Avoid English-language calques or untranslated clickbait.

Documented examples can reference celebrities in supplied corpus only as *research leads*; don't state the competitor allegations are true. Paraphrase external accounts with source IDs in FACT_MAP outside VO body. If the reference video audio has no transcript, don't claim you've copied or analyzed its exact spoken wording.
