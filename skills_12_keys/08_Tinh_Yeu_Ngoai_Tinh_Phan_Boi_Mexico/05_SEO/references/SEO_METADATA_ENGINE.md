# SEO METADATA ENGINE — MEXICO LONG-FORM

## Positioning
Viewer wants an emotionally legible betrayal and earned response, not vague generic "story time". Frontload exact emotional trigger in first ~120 characters of description: wife/husband/lover, proof and protagonist action. Consequence teased, not invented. Treat SEO as factual packaging; YouTube recommendation is not guaranteed by tags.

## Candidate keyword families (choose based on actual script)
`infidelidad`, `traición amorosa`, `mi esposo y su amante`, `historia de engaño`, `traición familiar`, `primer amor`, `divorcio`, `mi suegra`, `historia narrada en español`, `relatos de amor y desamor`, `novela romántica`, `historia de superación`, `mentiras y secretos`, `justicia emocional`, `amor propio`, `venganza sin violencia`.
Only 1–3 primary with 5–10 secondary; natural language in Spanish, not keyword spam. Avoid generic auto-tags `video, share, cellphone, upload` found in sample metadata.

## Description 4-part structure
1. Title event as narrative promise, no ending disclosed.
2. What protagonist stands to lose and first evidence clue.
3. Agency and unresolved dilemma, without false money/legal reward.
4. Gentle CTA and fictional storytelling positioning as appropriate.

## Integrity gate
Title not modified, no false "real life" claim, no implied documentary if fiction, no child exploitation as marketing and no medical/legal certainty beyond script. Alternate titles can test a different truthful perspective but not switch protagonist/plot. Chapters use actual TTS/audio rendering times; default only chapter names + placeholder `TBD`.
