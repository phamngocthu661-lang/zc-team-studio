# V1.1 Compatibility map
- Skill names / folder names: identical to V1.0.
- Workflow commands and order: identical step1, step2, step3(A/B/C), step4, step5(one repair), step4-post, step6.
- Existing output artifact names and JSON keys: preserved. Extra `review_id` is mandatory for each `authorized_patches[]` entry in new runs.
- CLI commands: original title-lock, outline-lock, assemble, qa-preflight, repair-once, seo-verify preserved. **Added:** editorial-diagnostics. **Added optional SEO args:** --qa-frozen and --baseline.
- Length default: technical 10,500–13,500 unchanged. Editorial target 11,800–12,600 advised, not an automatic rejection.
- `seo-verify` V1.1 uses fixed system technical bounds, NOT unauthenticated QA_FINAL min_chars/max_chars. A deliberately custom-length episode requires an explicit new profile/version instead of spoofing final QA JSON.
- V1.0 existing repaired episodes: never run STEP5 again. May run read-only diagnostics and thumbnail review.
- Standard library Python 3.9+, UTF-8. No new third-party dependencies.
