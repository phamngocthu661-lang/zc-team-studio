Cài cả folder này vào thư mục Skills; giữ đúng `SKILL.md`, `references/`, `scripts/` và `VERSION.txt`. Chạy `python scripts/pipeline_guard.py --help` nếu có Python.

Đọc `SKILL.md` trước, sau đó `references/SHARED_CROSS_SKILL_CONTRACT.md`. Quy trình tổng thể đặt trong bundle `JAPAN_STEP_CONTROLLER_V1.md`.
