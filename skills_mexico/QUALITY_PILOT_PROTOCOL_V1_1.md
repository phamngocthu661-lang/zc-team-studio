# MEXICO FAMILY V1.1 — REAL QUALITY PILOT (NOT A CLAIM OF COMPETITOR OUTPERFORMANCE)

**Goal:** Distinguish a skill that follows formatting from a skill that produces an emotionally persuasive YouTube story. Mechanical script tests cover continuity/artifact integrity, NOT human engagement.

1. Run Step1 on 3 different prompts: (A) unfair birthday/exclusion, (B) home takeover, (C) dependence / market humiliation. Require 5 divergent titles/prompt, 3 reference comparisons per title, separated click-vs-story rubrics, explicit deductions, no default all-90+ scores. Two reviewers blinded to suggested winner mark the title that sparks the most immediate injustice, real reversal, and genuine curiosity. Record disagreements.
2. Lock a title only after user selection. Run Step2: confirm every title phrase has a physical 7-Part scene, feasible property/payment route, 2 opponent counter-moves, narrator's moral cost, changed real-world balance at P6 and credible Part7.
3. Run Steps3 A/B/C to exact 70–80k Unicode-body chars. Have an es-MX speaker read P1 opening, P3 first boundary, P4 midpoint, P6 conflict and P7 ending. Note naturalness, emotional differences, slow sections, and repeated dialogue. Tool verification is necessary but not sufficient.
4. Step4 reviewer reads full SOURCE script, crosschecks actual title hook and title promise, logs exact spans, maps Pxx onto existing QA categories and issues NOT READY if climax only finds a paper, antagonist only repeats insults or Part7 is a sermon. Repair Step5 only at authorized byte zones; re-audit entire revised script.
5. Step6: A/B test title and thumbnail hypotheses only when published and permitted by channel workflow. Compare impressions→CTR and first-30-second retention + middle retention + average view duration against a suitable baseline. Control for topic, traffic source, audience, publication conditions. Don't attribute total views to title alone; use multiple videos, not one lucky spike.

**Pass for production pilot**: 3/3 title batches have a winner the blinded reviewer finds comparably compelling to source hooks by editorial judgment, 1 complete original script passes two independent es-MX literary reads and QA mechanics, zero legal/canon contradictions, three truthful thumbnail concepts. This is a *pilot decision*, not measured superiority over the competitor channel. If pilot fails, revise references/examples based on specific audit evidence, not by forcing 98–100 self-scores.
