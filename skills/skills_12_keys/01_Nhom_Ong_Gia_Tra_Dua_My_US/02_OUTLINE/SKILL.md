# SKILL 2 — 7-PART OUTLINE ENGINE
Read shared controller/contract, `references/TITLE_DNA_AND_FAMILIES.md`, and `references/STORY_BEAT_ENGINE.md`, `references/LOGIC_CANON_LEDGER.md`. STEP2 ONLY. Requires explicitly chosen locked title; never choose a new title for user.

## Workflow
1. Parse title into PERSON WRONGED / WHO BETRAYED / PUBLIC INSULT / HIDDEN TRUTH / REVEAL PROMISE / ENDING OBLIGATION.
2. Choose 1 main DNA + 1 secondary DNA, no more than 2 twinned reveal types, original US state/city, first-person American elder 55–75. Establish old man's former job as *tool* not auto-win. Choose a meaningful recurring object (folded receipt, toolbox, letter, deed, glass, photograph).
3. Produce exactly seven `[PART N]` outline sections. Each requires: time/location; narrative objective; public/private pressure; new evidence and its custodian; character competence+agency; state/timeline change; open loop and irreversible mini-payoff; natural Part-exit cliffhanger.
4. Three-step reveal ladder: (i) apparent insult, (ii) buried motive and concrete document/witness, (iii) father decides which lever he can legally pull. At least 2 red flags pre-twist, but no deus ex machina.
5. Hard logic: map bank account vs beneficiary vs deed/trust vs company shares, state law uncertainty, timeline, third-party permissions, knowledge before/after reveal. If father's plan depends on impossible ownership or criminal omnipotence, rewrite OUTLINE, not story later.
6. Ending action: protect an innocent person, enforce boundaries, make a costly principled choice. Repair/reconciliation is optional only if earned.
7. Generate `CURRENT_FINAL_OUTLINE.txt` physically in UTF-8 LF with title and profile line. If storage unavailable, disclose blocker; do not invent file SHA/video_id.

## Output
A. Locked title (exact); B. DNA and premise in one paragraph; C. 7 Part outline; D. CANON LEDGER; E. CAUSAL / DOCUMENT / KNOWLEDGE MATRIX; F. reveal map and listener emotions; G. outline file path, outline_sha256 and video_id calculated from bytes; H. prompt next `step3` A only after true saved file.

Default line `LENGTH_PROFILE: LONG_V12`. Optional user-chosen `LENGTH_PROFILE: COMPETITOR_CUT` must be locked at this step and consistently used in all proof tools, never flipped mid-script.
