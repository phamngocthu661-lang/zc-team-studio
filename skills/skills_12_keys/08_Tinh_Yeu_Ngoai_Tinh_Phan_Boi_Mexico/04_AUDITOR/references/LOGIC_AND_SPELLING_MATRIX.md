## Read protocol
Pass 1 map complete story and strong spans. Pass 2 check every Part against all rows above and reverse climax prerequisites. Pass 3 language proofreading in original Spanish without automatic one-size-fits-all correction. Emit only concrete defects. Exhaustive cross-part scans can be performed within S4, but the Writer gets only a SINGLE S5 repair batch.

## Severity & cross-references
P0 = fatal contradiction, P1 = major logic, P2 = clear objective typo/grammar or manageable continuity, P3 = subjective suggestion. If same wrong name occurs 9 times, include nine unique fixed windows in one batch with separate IDs or an unambiguous single replacement window encompassing a small paragraph. DO NOT use one broad whole-story replace.

### V1.1 addition: witness clock and lexical repetition
Explicitly test announcement time versus witness's described arrival and later testimony; check whether evidence is hearsay or direct. Inspect unnatural pronoun references and tautological phrases even if accent and conjugation are correct. Treat a false 20/20 timeline/language rating as an audit defect, not only prose issue.
