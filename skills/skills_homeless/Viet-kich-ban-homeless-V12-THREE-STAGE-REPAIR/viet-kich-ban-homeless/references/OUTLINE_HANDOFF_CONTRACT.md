## Handoff priority

If all fields are present, follow their **story intent, payoff, facts, and causal architecture**.

If some are missing, preserve the existing causal outline rather than inventing a replacement architecture.

Before drafting, run a silent `FORENSIC_LOGIC_GATE`. If an implementation detail is implausible, do not throw away the outline beat. Preserve the beat and repair the smallest mechanism needed to make it physically/legal/historically/professionally plausible.

## Never re-plan these unless user asks

- protagonist identity;
- property identity;
- title-level discovery;
- antagonist motive;
- clue solutions;
- final reveal;
- ending resolution.

## Allowed drafting freedom

- minimal plausibility repair that preserves the intended beat/payoff;
- micro-actions;
- natural dialogue;
- weather;
- sensory detail;
- minor repair obstacles;
- transitional time movement;
- small community interactions;
- technical staging consistent with outline.


## V2.3+ Handoff hard rule

If the outline includes structured ledgers, load them into `CANON_STATE_MATRIX.md` before writing prose. Do not flatten them back into a static continuity list.

If an older outline lacks the ledgers, build the matrix internally before drafting. Missing state data is not permission to guess silently when a small mechanism repair can make it explicit.
