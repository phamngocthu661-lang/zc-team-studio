# OUTLINE V1.3 — SEVEN PARTS, MEANINGFUL ESCALATION, SPECIFIC MEXICAN FAMILY PSYCHOLOGY

Read after V1.2 NICHE_CANON_LOCK and V1.1 HOOK_TO_PAYOFF_ARCHITECTURE. Preserve exact LOCKED_TITLE, 7-Part/70k–80k contract, scene IDs, eight canon ledgers, outline SHA handoff.

## Anti-formula principle
Seven Parts are not seven variations of "my daughter was rude, so I said no." Create change through **different kinds** of pressure: daily dependency, private shame, property/financial uncertainty, broken sibling alliance, an earned discovery, a decision that hurts narrator too, a consequence that cannot be erased by a speech. More noise/violence is not escalation.

## Mandatory STEP2 outputs (additive, never replace original outline)
1. `FAMILY_RELATIONSHIP_ASYMMETRY`: give the elder, wrongdoer, favored relative, conflicted ally an earlier history; the offender must gain something by choosing the wrong action and risk something by repairing it. Explain which exact past act made elder trust this child. Not every relative can speak with the same villain voice.
2. `REVERSAL_VARIETY_MAP`: map headline's main impending encounter to concrete physical and emotional payoff in P6; list two alternate response strategies considered and rejected, each with cost. Avoid a preannounced `le negué` becoming the ONLY dramatic beat.
3. `PART_STATE_DELTA_TABLE` (7 rows): BEFORE state, NEW evidence/act, mother's decision, opponent adaptation, paid cost, AFTER state, new viewer question. No row may have all state columns unchanged. A "remembered childhood scene" needs a live consequence in present time.
4. `CONFLICT_LADDER`: P1 affront, P2 pattern/contradiction, P3 first contested boundary, P4 **change of hypothesis** caused by seeded evidence, P5 opposing pressure that threatens at least two stakes, P6 live consequential choice with credible authority, P7 earned relational aftermath. Flexible scene order; never force a twist when no causal material supports it.
5. `ANTI-REPETITION_SCENE_MATRIX`: for every scene classify primary function [new action, changed leverage, new evidence, relational nuance, monetary/practical cost, irreversible choice, necessary decompression]. No 3 consecutive scenes doing only repeated argument/rumination. Two scenes that do exactly the same thing => merge or replace.
6. `EMOTIONAL_PRICE_LEDGER`: what does the mother lose BY acting (contact, money, pride, convenience, solitude, certainty)? Contrast "winning the house" and "losing old family fantasy" with specific behavior in P7, not an abstract moral essay.
7. `TWIST_FAIRNESS`: each major reveal requires planted antecedent and an impact that changes an action; no secret millionaire, automatic notarial power, sudden confession that repairs every harm.

## 5–8 SCENES PER PART — BUT NO PADDING
Prefer 5–8 scene cards as the existing contract specifies; combine a beat rather than create a meaningless filler card. Action / goal / antagonist move / obstacle / small earned payoff / state delta. The 74.5k manuscript should have *complexity, not repeated sentences*. One quiet family scene can provide stronger tension when it changes what narrator is willing to sacrifice.

## DISTINCTIVE MEXICO HUMANITY (NOT STEREOTYPE)
Use believable work, costs, neighborhood distances, bus routes, colonia, mercado, clinic wait and family table details ONLY as plot-functional texture. Avoid making a "Mexican woman" synonymous with helplessness. Correct kinship: `consuegra` = parent of child's spouse, `nuera` = son's wife, `suegra` depends on speaker. Show familial love and obligation without forcing reconciliation.

## Acceptance gate
A STEP2 outline MUST be marked `OUTLINE_NOT_READY` if title action is merely asserted, if P3–P5 can be rearranged without consequence, if P6 depends on newly materializing authority/document, if mother makes no costly choice, or if same family accusation repeats without altered stakes. Existing numerical preflight >=95 cannot override these manual failures. Annotate actual scene IDs supporting the verdict.
