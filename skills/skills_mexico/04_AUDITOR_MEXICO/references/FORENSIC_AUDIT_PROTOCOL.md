## Root cause diagnosis
Each finding follows `OBSERVATION → EXACT ANCHOR → OTHER OCCURRENCES → ROOT CAUSE → VIEWER HARM → OBJECTIVE ACCEPTANCE TEST → SMALLEST CLOSED EDIT ZONE`. Avoid simply saying "plot hole". If the best fix requires changing title or fully restructuring outline, escalate instead of assigning a giant manuscript zone.

## Strong span preservation
Identify at least one important early setup, one emotionally distinctive dialogue, one unique object setup, a turning-point choice, and a final echo that must remain unless separately authorized. Each exact anchor must physically exist inside named Part; QA tools reject fictional anchors.

## Saturation protocol
First audit finds Pxx; reread full script. The final saturation entry contains `complete:true`, current `body_sha256`, `new_defect_ids:[]`, source-bound explanation of checks performed. If new defects appear in a later sweep, repeat full process; don't merely delete their IDs.

## V1.1 red-team weak title fulfillment
A strong source is not one where the narrator merely finds a receipt, asks a question or makes an unexplained public statement. Find the title's future promise, the scene of actual decisive choice, and its durable human consequence. Compare the *mechanism* only with 3 user-provided top references (E01 birthday contrast, E02 house takeover, S01 public insult reversal); don't borrow their plots. Repetition or a paper-only climax is an actionable Pxx defect even with impeccable money and name ledgers.
