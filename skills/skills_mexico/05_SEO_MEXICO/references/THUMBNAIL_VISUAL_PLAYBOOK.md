# THUMBNAIL VISUAL DNA — THREE SEPARATE IMAGES, 16:9

## Common locks
- Core context remains the actual offense in the script. Authentic Mexican domestic setting if title is house-based; wedding remains wedding; family meal remains family meal. No restaurant-to-courthouse shift purely for spectacle.
- 60–78-year-old realistic Mexican older woman, dignified, detailed micro-expression, mature hands/skin; no caricature. Family antagonist visible only if helpful, and characterization consistent with script.
- 16:9 TRUE width/height ratio: 1920×1080 or 3840×2160. Photorealistic cinematic editorial still, not cartoon. Camera focal subject is face + emotionally meaningful object.
- Limit central subjects to 2–3. Keep safe space for 2–6-word Spanish overlay if the user wants text. Strong contrast, legible at mobile scale; one readable proof object but don't depend on tiny unreadable document text.
- These are prompts, not generated images. Do not invent unprovided likenesses of real people. Avoid legally inaccurate photo proof (arrest, forged documents, judge attire) unsupported by script.

## Prompt 1 — HUMILLACIÓN DIRECTA
Camera: eye-level close-up woman to right/left third; relative refusing her in same scene, antagonists soft-focus behind. Object: invitation/plate/seat/door sign/moving suitcase. Emotion: restraint while hurt; vivid human expression. Lighting natural, non-horror. Visual question: "¿Por qué la apartaron?"

## Prompt 2 — LA PRUEBA / LOS PAPELES
Camera: slightly elevated over-the-shoulder three-quarter from folder/document toward her face, distinct setting or room corner but still same home/venue context. Object visible foreground keys/receipt/phone/deed with NO fabricated legible legal information. Emotion: realization turning to resolve. Visual question: "¿Qué descubrió?"

## Prompt 3 — EL LÍMITE / LA DECISIÓN
Camera: dynamic medium two-shot 35–50mm, woman physically closing a door, setting down keys, moving a folded paper, or refusing a relative's gesture. Counterreaction visible but not cartoonish. Emotion: dignity/control; consequence imminent. Visual question: "¿Qué decidirá ahora?"

## Differentiation checklist
(1) Main camera angle differs, (2) foreground action differs, (3) dominant emotional beat differs, (4) lighting/surface palette differs, (5) at least 15–30% secondary layout/props changed, (6) core setting category and event held stable, (7) never collage / triptych / contact sheet. On user request for exactly 3 images, image-generation tools must run separate outputs; this skill on its own only provides prompts.

## Overlay wording
Prefer original Spanish text (if requested) e.g. `¡ESA CASA ES MÍA!`, `¿ME VAS A ECHAR?`, `NO FIRMÉ NADA`; choose only if accurate to scene. Max ~2 rows and 2–6 words, yellow/white/rose high contrast with dark outline. Avoid enormous paragraph, misleading all-caps reveal, long titles filling the face. Text-free renders can later be composed manually for pixel-perfect Spanish accents.

## V1.1 one-glance hook test
At phone scale, an adult Mexican viewer should be able to tell WHO is humiliating WHOM and which object/social position represents the insult. Variant 3 should show the elder's *choice*, not yet another startled face holding the same envelope. `Humiliation / Unfair contrast / Decisive action` need distinct photographic evidence; avoid confusing mother-in-law/consuegra cast or dressing a retiree as a judge if absent from script.

## V1.2 FIRST-PERSON MATRIARCH LOCK
Only the real first-person older mother/grandmother and offending RELATIVE are primary subjects. Do not translate wedding/bus-terminal family betrayal into anonymous rich-man moral rescue. Three images: mother betrayed → asymmetric family choice → she refuses/decides; no abstract crying/call image as promised twist. If a child is present, keep child secondary. No misleading exact 30–45min claim without measured finished audio.
