# Viết Giàn Ý Người Hầu — Skill Package

## Cách dùng
1. Dùng `SKILL.md` làm instruction chính cho skill.
2. Các file trong `references/` là tài liệu nguồn gốc để kiểm tra lại DNA khi cần.
3. Khi bắt đầu chat mới, chỉ cần gửi tiêu đề video.
4. Skill sẽ tự chọn DNA A/B/C và tạo giàn ý; không cần upload lại 3 DNA.

## Input tối thiểu
`[NEW VIDEO TITLE]`

## Output
Story DNA Match → Story Core → Retention Map → Detailed Outline → Payoff Audit → Quality Score.

## Phạm vi
Chuyên niche Mafia Boss × Maid / Waitress / Secretary / Underestimated Woman / Hidden Expert.
Không tự viết full script, thumbnail, SEO hay tags.
