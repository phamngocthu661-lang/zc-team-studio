# Kiểm Tra Kịch Bản Người Hầu — v1.1

Skill QA/revision dành riêng cho workflow:

**TITLE → Viết Giàn Ý Người Hầu → Viết Kịch Bản Người Hầu Từ Giàn Ý → Kiểm Tra Kịch Bản Người Hầu → Revision**

## Giữ nguyên lõi tốt của skill QA gốc
- 2 full reads bắt buộc;
- exhaustive Patch Ledger, không giới hạn lỗi;
- exact location + occurrences;
- MASTER BASELINE;
- strong-span preservation;
- surgical patch mặc định;
- Authorized Diff Gate;
- length regression;
- dependency simulation;
- 2 blind reads sau revision;
- chống “càng sửa càng ngắn”.

## Đã thay key-specific rules
Bỏ default của key cũ như:
- heritage/restoration voice;
- hidden room/material-aging/property/inheritance-centric audit;
- U.S. 40+ heritage assumptions.

Thay bằng:
- Mafia Boss × Maid/Waitress/Underestimated Woman;
- DNA A/B/C + outline fidelity;
- dynamic N-Part lock;
- standard 44,000–48,000 chars; recovery 40,000–55,000; hard max 55k;
- heroine agency + competence;
- Boss protection/consent boundary;
- antagonist motive;
- action/security/injury continuity;
- relationship/power-balance continuity;
- YouTube-safe fictional crime framing;
- American-English dark-romance/TTS prose.

## Review mode
User nói `đánh giá`, `QA`, `forensic`, `kiểm tra` → review + Patch Ledger rồi dừng.

## Revision mode
User nói `sửa theo đánh giá`, `patch`, `rewrite theo QA` → apply frozen ledger, preserve strong spans, run regression gates, output stable revised script.
