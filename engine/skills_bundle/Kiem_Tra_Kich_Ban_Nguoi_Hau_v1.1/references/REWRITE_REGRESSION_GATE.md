# REWRITE REGRESSION GATE — NGƯỜI HẦU V1.1

## PASS 0 — LOAD CONTRACT
Lock OPB + CRB, outline/title/DNA, Part count, exact chars, exact words, Patch Ledger, prior QA score if any, strong spans, user scope.

## PASS 1 — PATCH APPLICATION
For each Pxx/Oxx:
- APPLIED?
- ROOT ISSUE REMOVED?
- DEPENDENCIES UPDATED?
- LENGTH INTENT RESPECTED?
- STRONG SPAN UNDAMAGED?

Any NO → fail.

## PASS 2 — AUTHORIZED DIFF
Every change must map to approved patch/dependency/authorized copyedit family.
Unmapped creative rewrite → revert.

## PASS 3 — OUTLINE / PART REGRESSION
If outline available:
- exact N Parts;
- 1:1 Beat mapping;
- Story Core intact;
- Primary DNA dominant;
- open-loop schedule intact;
- climax/payoff intact.

## PASS 4 — LENGTH / WORD REGRESSION
- standard target 44k–48k chars unless explicit override;
- standard word target 7,400–7,650;
- strict total words <8,000;
- <=55k hard max and >=40k floor unless explicit override;
- preservation bands against CRB;
- cumulative drift check against OPB;
- no unexplained shrinkage.

## PASS 5 — CANON / CHARACTER / RELATIONSHIP
Check names, jobs, ages, motives, knowledge, injuries, objects, evidence, security access, trust, consent and power balance.

## PASS 6 — KEY-SPECIFIC RULES
Check:
- heroine agency;
- competence seed/process/payoff;
- dual-pressure sequence where contract requires;
- Boss protection boundary;
- antagonist motive;
- action complication;
- adrenaline-crash consequence;
- no unsupported new threat layer;
- forbidden trope vocabulary;
- zero bracketed TTS cues.

## PASS 7 — LOGIC / REAL-WORLD
Re-run travel, spatial/action, security, evidence, professional, money/contract, human incentive checks.

## PASS 8 — HOOK / RETENTION / HUMAN PROSE / YOUTUBE
Re-run all publication-readiness checks.

## PASS 9 — BLIND FULL READ #1
Read revised script as new script, not through old ledger.

## PASS 10 — BLIND FULL READ #2
Line-by-line full read.
If new actionable defect appears:
- classify exactly as R — REGRESSION / L — LATENT OMISSION / N — NEWLY APPLICABLE / P — PREFERENCE;
- repair at smallest radius;
- map internal late-fix dependency;
- rerun relevant gates + at least one final full read.

## PASS 11 — STABILITY TEST
Ask:
“If this exact revised script were reviewed again now, is there any item I would certainly put in a Patch Ledger?”

Yes → repair before output.
Pure preference only → PASS.

## PASS 12 — SCORE STABILITY
- recompute current absolute score with the same frozen rubric;
- if previous score exists, compute corrected prior score and comparable revision delta;
- score decrease must be attributed; latent omissions are audit debt, not revision blame.
