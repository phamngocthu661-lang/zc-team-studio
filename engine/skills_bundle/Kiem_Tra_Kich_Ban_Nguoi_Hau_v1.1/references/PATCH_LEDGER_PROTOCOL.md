# PATCH LEDGER PROTOCOL — NGƯỜI HẦU V1.1

## PURPOSE
Patch Ledger là edit contract đầy đủ cho một lần sửa.
Không giới hạn Pxx/Oxx.

## SEVERITY
- **P0** — fatal story/platform/outline/logic defect.
- **P1** — major defect damaging title promise, Part architecture, causality, character boundary, retention or YouTube readiness.
- **P2** — meaningful continuity/credibility/voice/repetition defect.
- **P3** — micro actionable copy/prose/detail defect a careful editor would actually fix.

## EXACT LOCATION
Mỗi patch:
- Part N;
- scene/Beat context;
- quote anchors hoặc line range.

## PATCH FORMAT
### P01 — [P0/P1/P2/P3] Short name
**Vị trí:** ...
**Contract violated:** TITLE / OUTLINE / DNA / PART / LENGTH / WORD LOCK / TTS / CHARACTER / LOGIC / RETENTION / YOUTUBE / PROSE / LANGUAGE
**Score Component:** A / B / C / D / E / F / G / H
**Delta Class (if prior QA exists):** KNOWN / R / L / N / P
**Lỗi:** ...
**Cần sửa thành:** ...
**Cách sửa:** ...
**Dependencies:** ...
**Length Intent:** KEEP / ADD ~N / CUT ~N / REDISTRIBUTE
**Phạm vi:** LOCAL / SCENE / CHAIN / PART / GLOBAL
**MUST PRESERVE:** ... nếu cần

## RECURRING ROOT ISSUE
Group root issue được phép nhưng enumerate mọi actionable occurrence:
- O01 exact location → action
- O02 ...

Strong intentional occurrences ghi PRESERVE.

## REWRITE ENTIRE PART
### Pxx — [P0/P1] REWRITE ENTIRE PART N — REQUIRED
**Mapped Outline Beat:** ...
**Root problem:** ...
**Why local patching insufficient:** ...
**MUST CHANGE zones:** ...
**MUST PRESERVE exact/near-exact:** S01...Sn
**MUST PRESERVE functions:** title anchor / clue / loop / competence / romance beat / action consequence / reveal / payoff
**Dependencies:** ...
**Baseline chars:** ...
**Target chars:** ...
**Length Intent:** ...
**Method:** SCAFFOLD RECONSTRUCTION

## PATCH CLOSURE SIMULATION
Before freeze, simulate each Pxx against:
- earlier setup;
- later payoff;
- knowledge;
- object/evidence/weapon state;
- injury state;
- relationship/consent state;
- antagonist motive;
- Part/outline mapping;
- total character target/hard max;
- word target/strict <8k;
- zero-bracket TTS;
- YouTube safety;
- strong spans.

## PATCH FREEZE
After review:
- IDs stable;
- rewrite uses approved IDs;
- no new creative rewrite agenda.

Late latent issue found during internal blind audit may be fixed only at smallest radius and must pass all regressions before final output.
