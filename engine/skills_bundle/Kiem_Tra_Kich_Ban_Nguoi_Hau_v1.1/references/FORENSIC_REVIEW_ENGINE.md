# FORENSIC REVIEW ENGINE — MAFIA MAID V1.1

## PASS 0 — SOURCE + BASELINE LOCK
Record:
- exact title;
- outline if available;
- Primary DNA/Content Family if available;
- N outline beats;
- script Part count;
- OPB + CRB;
- exact chars per Part + total;
- exact total words;
- standard target 44k–48k chars + 7,400–7,650 words; strict <8k; hard max 55k;
- prior QA score/ledger if available;
- strong spans.

## PASS A — TITLE / OUTLINE / DNA FIDELITY
Check:
- every title anchor matters;
- script does not silently change profession/role/relationship/event/amount promised by title;
- Story Core facts remain stable;
- each Script Part performs its mapped Outline Beat;
- no added/deleted/merged/split/reordered Beat;
- Retention Map loops open/advance/close at correct stages;
- Primary DNA remains dominant;
- no accidental DNA soup;
- final payoff matches title + outline.

## PASS B — CHARACTER CANON
Track:
- names/spelling;
- age/role/job/training;
- finances/family burden;
- injuries/limitations;
- relationships/forms of address;
- knowledge;
- trust/romance/power balance;
- resources and authority.

## PASS C — HEROINE AGENCY & COMPETENCE
Test:
- does she materially change outcomes?
- is competence seeded before decisive use?
- is expertise shown as observation → check → inference → action?
- does technical detail affect causality?
- is she still relevant at climax?
- does fear remain physiologically credible without erasing action?
- is required dual-pressure scene present under current writer contract?

## PASS D — MALE LEAD / ROMANCE BOUNDARY
Flag:
- violence/roughness/non-consensual touch against heroine;
- coercive sexuality framed as romance;
- protection replacing heroine agency;
- long tactical monologue under danger;
- romance leap without earned trust;
- forced marriage/coronation mode unsupported by title/outline;
- vulnerability reveal inconsistent with character arc.

## PASS E — ANTAGONIST / THREAT LOGIC
Check:
- concrete motive;
- leverage;
- escalation cause;
- knowledge/access;
- believable mistake/exposure;
- no stupidity for plot convenience;
- no surprise mastermind layer invalidating outline;
- meaningful secondary antagonist gets the choice/outcome promised by outline;
- confirmed betrayer resolution matches DNA/outline.

## PASS F — CAUSALITY / KNOWLEDGE
Every major sequence should read:
**CAUSE → ACTION → EVIDENCE → INTERPRETATION → DECISION → CONSEQUENCE**.
Reject:
**COINCIDENCE → PERFECT CLUE → PERFECT SOLUTION**.

Check knowledge source before every key decision.

## PASS G — ACTION / SECURITY / PHYSICAL LOGIC
Check:
- room/door/vehicle/cover/line-of-sight geography;
- travel time;
- access/security/surveillance;
- weapon/resource possession;
- communication timing;
- injury/fatigue consequences;
- action complication;
- no implausible endless combat capacity;
- no magically functioning damaged tech;
- no rescue arriving only because plot needs it;
- adrenaline crash/recovery after set-piece where required.

## PASS H — PROFESSIONAL / TECHNICAL CREDIBILITY
Only audit domains actually used:
- medicine;
- security;
- finance/auditing;
- contracts/legal;
- logistics/cargo/customs;
- ballistics/forensics;
- art/authentication;
- language/translation;
- other outline-specified competence.

Heroine may be expert, but cannot possess every unrelated license/skill without setup.
Technical detail must remain non-instructional for real wrongdoing.

## PASS I — HUMAN INCENTIVES
Ask:
- what does each person risk losing?
- why do they stay/leave/trust/lie?
- does financial desperation affect decisions realistically?
- does possessiveness have story consequence without becoming abuse?
- do witnesses/henchmen/secondary antagonists have plausible motives?
- are reactions proportional to what each person knows?

## PASS J — HOOK / RETENTION
Hook:
- clicked-title promise activated quickly;
- concrete anomaly/danger/status contrast;
- no biography dump;
- no premature main-payoff reveal;
- no generic “everything changed” filler;
- clean enough for YouTube.

Long-form:
- meaningful shift roughly every 450–550 words on average;
- every Part advances a loop/stakes/relationship/evidence;
- midpoint materially changes story state;
- quiet scenes earn intimacy/contrast/decision;
- no repeated conflict without new information;
- climax solves established question;
- ending closes correct loops.

## PASS K — HUMAN PROSE / LANGUAGE
Run HUMAN_PROSE checklist:
- American English;
- third-person past tense unless outline locks otherwise;
- no repeated AI-cinematic constructions;
- distinct character voices;
- Boss dialogue concise without becoming robotic;
- heroine voice changes naturally inside expertise;
- zero bracketed stage/audio/performance cues under standard TTS contract;
- no camera/editing/production notes;
- no recap opening at new Parts;
- forbidden trope vocabulary check.

## PASS L — YOUTUBE READINESS
Run current-key YouTube checklist.

## PASS M — EXACT DETAIL SWEEP
Inspect every:
- name/spelling;
- age;
- date/time/duration;
- dollar amount/debt/payment;
- address/location/distance;
- room/floor/vehicle;
- weapon/object/document;
- injury;
- relationship status;
- job title;
- code/serial/transaction detail if plot relevant.

## PASS N — SCORE + DELTA ATTRIBUTION
- Score only with `FORENSIC_SCORE_RUBRIC.md`.
- Every root defect gets one primary Score Component.
- If prior QA exists, classify newly found defects `R/L/N/P` using `REVISION_SCORE_DELTA_PROTOCOL.md`.
- Never blame a revision for an `L — LATENT OMISSION`.

## PASS O — REPAIR SIMULATION
For each patch:
- earlier setup dependency?
- later payoff/callback?
- knowledge state?
- evidence possession?
- injury timeline?
- romance state?
- DNA/outline consequence?
- Part length effect?
- protected strong-span impact?

Record dependency before ledger freeze.

## COMPLETION RULE
Audit incomplete until:
- two full reads complete;
- all actionable occurrences represented;
- dynamic Part and length contract checked;
- current-key non-negotiables checked;
- deterministic score computed;
- repeated-QA delta attribution computed when applicable;
- repair simulation closed;
- no vague global compression order can spill into passed text.
