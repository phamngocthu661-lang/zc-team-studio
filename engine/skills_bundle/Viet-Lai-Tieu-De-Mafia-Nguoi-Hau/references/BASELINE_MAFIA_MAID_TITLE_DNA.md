## E. PERFORMANCE LESSONS

1. `Mafia Boss` is a core classification anchor across the niche.
2. Female occupational archetypes are not decorative; they frame status contrast and audience fantasy.
3. One concrete incident beats generic romance setup.
4. Direct quote works best when it contains danger, jealousy, possession, or competence.
5. `Until / Unaware / Then` work because they encode reversal, not because the words themselves are magical.
6. Family-member keywords become powerful when they create healing/protection stakes.
7. Hidden competence is stronger when skill is concrete: language, warning, medical action, accounting, fighting, etc.
8. Generic `shocked everyone` is strongest only after a highly specific setup.
9. Concrete payoff often beats generic payoff.
10. Low-view recent titles should not override older repeated winners without velocity evidence.
