# CHANGELOG — V1.3

## Output simplification
Default full SEO output is reduced from 19 visible sections to exactly 12 visible sections:
1. TITLE SET — LOCKED TITLE + 2 NEW TITLES
2. SEO DESCRIPTION
3. SEO TAGS
4. HASHTAGS
5. THUMBNAIL HYPOTHESES
6. FINAL THUMBNAIL CONCEPT
7. FINAL CHATGPT IMAGE PROMPT
8. 8-SECOND VIDEO HOOK STRATEGY
9. FINAL 8-SECOND VIDEO GENERATION PROMPT
10. LOCKED TITLE × THUMBNAIL × HOOK CHECK
11. FINAL QA
12. FINAL CHANNEL RECOMMENDATION

## Internal-only diagnostics
The following still run internally but are hidden by default:
- Input Diagnosis
- Content Family
- A/B/C classifier and gate math
- Why This Channel
- Video Selling Point
- Click Psychology
- Packaging Strategy
- Packaging Fatigue analysis
- internal revision-pass notes

## Title policy retained
- Locked/Primary Title remains verbatim.
- Exactly 2 new/supporting titles are generated.
- Each new title must be ≤100 visible characters.
- New titles never auto-replace CURRENT FINAL TITLE.

## No classifier/QA logic weakening
The simplification affects display surface only. DNA definitions, weights, gates, hook rules, thumbnail scoring and QA hard-fail rules remain active internally.
