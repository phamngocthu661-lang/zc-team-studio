# FORENSIC LOGIC GATE V1.4
## PRE-DRAFT PLAUSIBILITY AUDIT FOR HOMELESS × ABANDONED PROPERTY × HIDDEN LEGACY

This gate runs SILENTLY before drafting each Part and again before any major mechanism/reveal.

# A. CORE PRINCIPLE

**PRESERVE THE PAYOFF. REPAIR THE MECHANISM.**

If the outline says a hidden room exists, keep the hidden room. If “how it stayed hidden” is weak, repair the concealment.
If the outline says an old ruler opens it, keep the ruler as the access logic. If using the original as a wrench would be reckless, measure it and make/use a working duplicate.
If the outline says a covenant changes ownership, keep the covenant. If one paper cannot legally do that by itself, add corroboration/chain-of-title review.

Never sacrifice the title promise merely to prove realism. Make realism support the promise.

# B. 10-QUESTION SCENE TEST

Before every major discovery, answer internally:
1. Why does this clue/object/room still exist?
2. Why was it not found earlier?
3. Why can the protagonist find it now?
4. What exact competence/action causes discovery?
5. What would age/environment physically do to it?
6. Does the tool/weight/scale/load/timing work?
7. Who has authority to touch/open/remove/test it?
8. Who knows what at this exact moment?
9. What independent evidence would a skeptic demand?
10. Is the scene causal, or merely convenient for the writer?

If #10 is “convenient,” rewrite the mechanism.

# C. HIDDEN-FOR-DECADES / CENTURIES TEST

A large secret cannot survive because “people trusted plans” alone. Stack credible factors as needed:
- false exterior feature / blind window;
- later wall/repair hiding seam;
- inaccessible cliff/façade/attic;
- unsafe or restricted area;
- authoritative early survey already wrong;
- later surveys copied the inherited base;
- property too large for casual dimensional comparison;
- archive dispersed / room renumbered / ownership fragmented;
- concealment intentionally makes outside and inside appear consistent.

The answer should make the viewer think: “I can see how everyone missed it,” not “everyone before her was stupid.”

# D. PHYSICS / MATERIALS

## Heavy objects
Concrete slabs, stone panels, safes, beams, engines, machinery and heavy doors obey mass. Use:
- wedges;
- jacks;
- chain hoist / come-along;
- cribbing;
- leverage;
- multiple people;
- machinery;
- partial disassembly.

## Old mechanisms
After decades/centuries expect some combination of:
- corrosion;
- seized spindle;
- wood movement;
- sagging hinge;
- settlement;
- dust;
- brittle leather;
- degraded lubricants;
- warped members.

A surviving mechanism may still work PARTLY. Often the best scene is:
**old design identifies/releases → modern conservation skill finishes safely.**

## Measurement
- Never use a full-size historical ruler directly on a reduced drawing as if scales match.
- Convert units to drawing scale, use proportional dividers, scaled measurements, or digital calibration.
- Recheck from independent control points.

# E. ARTIFACT / CONSERVATION HANDLING

If an object is rare or historically significant:
- photograph in situ;
- document context;
- avoid unnecessary contact;
- do not use original object for force/torque if a replica can perform the mechanical test;
- use gloves appropriate to material when needed;
- involve conservator/engineer/authority when risk justifies it.

Do not overdo museum procedure in every scene. Add only enough to make competence credible.

# F. AGING / SEALED-SPACE REALISM

“Untouched” means arrangement undisturbed, NOT materials unchanged. Show appropriate aging:
- rust bloom;
- hardened/cracked leather;
- moth loss;
- faded cloth;
- foxed paper;
- dry/checking wood;
- settled dust;
- stale/mineral air.

If condition is unusually good, explain preservation:
- dark;
- dry;
- stable roof;
- shutters;
- limited but sufficient airflow;
- no repeated human traffic;
- no animal access.

# G. LEGAL / TITLE / INHERITANCE REALISM

Do not use “magic paper.”

For major public or ownership consequences, move through:
DISCOVERY → AUTHENTICITY → CORROBORATION → LEGAL INTERPRETATION → TEMPORARY ACTION → FINAL/PROVISIONAL OUTCOME.

Possible corroboration:
- church/parish copy;
- county/municipal register;
- tax record;
- notary book;
- later official recognition;
- long-standing practice;
- seals/watermarks/ink/paper;
- independent descendants/witness records.

A protagonist can understand the implication without pretending to be the lawyer:
“If valid, this changes the question.”
not:
“This proves I own the mountain.”

# H. ANTAGONIST / INSTITUTION COMPETENCE

A sophisticated developer, bank, estate, county, museum, attorney, police department, hospital, or corporation must behave like an institution with resources.

If they have spent years on a project, assume believable due diligence unless the story explicitly explains why not.

Better conflict:
- they know the customary rights but classify them as revocable; new covenant changes classification;
- they know a building is old but not that a specific sealed record exists;
- they know a claim exists but do not have corroborating evidence.

Bad conflict:
- billionaire developer never checked title;
- lawyer ignores obvious will;
- museum staff never counted an obvious extra room;
- police ignore basic evidence only so protagonist can be right.

# I. HUMAN INCENTIVE REALISM

Hardship changes choices. A protagonist with $43, unstable housing, debt, a child, or no career does not casually reject:
- safe housing;
- salary;
- medical help;
- inheritance;
- legal settlement.

If she rejects or delays, show why. Better:
- read contract;
- ask guarantee;
- verify condition;
- counteroffer;
- seek independent advice;
- choose after cost becomes concrete.

# J. CAREER / CREDENTIAL REALISM

Do not reward a young/inexperienced protagonist with an implausibly senior title. Match role to proof:
- site conservation coordinator;
- restoration field technician;
- apprentice/junior conservator;
- project coordinator under licensed architect/conservator.

Then show path:
training → accredited coursework → responsibility → later advancement.

# K. EVIDENCE TRIANGULATION

For major historical/legal/public reveal, prefer:
1. physical room/object evidence;
2. primary record;
3. independent outside corroboration.

A letter is allowed to explain motive. It should rarely prove the entire public outcome by itself.

# L. EXACT DETAIL / CHEKHOV RULE

If narrator emphasizes:
- 4:17;
- exact serial;
- exact distance;
- exact unusual price;
- repeated date;
- distinctive initials;
then it creates expectation.

PAY IT OFF, USE IT AS VERIFICATION, OR REMOVE THE EMPHASIS.

# M. THEME NATURALISM

Avoid “the universe wrote the theme for the protagonist.”

Weak:
father says exact quote → dead king wrote exact same quote 200 years earlier.

Better:
father teaches one craft principle; old evidence shows a different craftsman reaching a related idea in different words; protagonist connects them herself.

Best:
the theme is visible in what both people DID, not what they conveniently inscribed.

# N. DOCUMENT-DENSITY RULE

Administrative evidence is powerful because it feels real, but too much creates listening fatigue.

If 3+ records arrive consecutively:
- combine routine items;
- preserve only the entries that change hypothesis;
- interleave argument/action/pressure;
- remove 8–12% clerical repetition if the chain remains clear.

# O. FINAL RED-TEAM PASS

Before output ask:

**What would a skeptical viewer write in the comments?**

Look specifically for:
- “How did nobody notice that?”
- “That thing would weigh hundreds of pounds.”
- “That mechanism would be rusted solid.”
- “Why is she using an antique as a wrench?”
- “A lawyer/developer would already know this.”
- “That document would not instantly make her owner.”
- “Why would she turn down free housing?”
- “How did she know that?”
- “Why is every clue perfectly waiting for her?”
- “Why mention the exact time if it never matters?”

If the imagined comment is correct, repair the scene before sending it.


# P. V1.4 STATE + PERIOD ADDENDUM — HARD GATE

Before approving a scene also ask:
1. What is the current Event ID / season / year?
2. What is the current money state after all prior transactions?
3. Has this proper place/mechanism name been introduced yet?
4. Does this actor's role/authority permit the action/dialogue?
5. Is this office title/legal phrase/procedure period-appropriate? If uncertain, generalize.
6. Is this cold-open event being duplicated as a second discovery?
7. Does this scene move chronology forward, or is an explicit flashback marker required?
8. If legal/institutional resolution needs months, is the story using PROCEDURAL mode rather than forcing instant resolution?

A scene that passes physics but fails state continuity still FAILS.
