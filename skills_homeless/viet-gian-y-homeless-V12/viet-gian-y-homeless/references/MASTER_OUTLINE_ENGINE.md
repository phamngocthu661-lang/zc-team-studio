# MASTER OUTLINE ENGINE V2.3.1 — HOMELESS / ABANDONED PROPERTY

This reference supplements `SKILL.md`. Also obey `CROSS_SKILL_QUALITY_CONTRACT.md`; if older length/scoring wording conflicts with the shared contract, the shared contract wins unless the user explicitly overrides.

## CORE MODEL

HEART = quiet humanity + competence + restoration + kindness + belonging.
SPINE = anomaly + mystery + clue chain + escalating pressure + staged reveals + consequence.

The outline must support a finished script in the shared **HARD RANGE 70,000–80,000 characters inclusive**, with a preferred operating zone of **74,000–78,000 characters** unless the user explicitly overrides with a new current range. Character count is authoritative; word count is telemetry only. 69,999 and 80,001 are both FAIL. Extra length must come from functional story work, never padding.

It must also produce a state-safe handoff using `CANON_FORENSIC_HANDOFF.md`. A compelling outline with unresolved timeline/money/authority/naming state is NOT ready.

## TITLE CONTRACT

Decode every explicit anchor: protagonist state, age, price, property, location, object, hidden place, promised discovery, implied consequence.

Every anchor must have SETUP → DEVELOPMENT → PAYOFF.

## DNA ROUTING

Read all packaged DNA profiles and keep them separate.
Select ONE PRIMARY DNA by fit to protagonist, conflict, story engine, emotional promise, discovery structure and payoff.
Hybrid only for one clearly declared borrowed function.

DNA controls market-native emotional/pacing identity.
V2 controls structural retention quality.

## V2.3 EARLY + MACRO RETENTION SPINE

### FIRST 5-MINUTE HARD SURVIVAL LADDER
~0–200 chars — title promise contact
by ~400 — physical/verifiable proof
by ~650 — stakes
by ~1,100 — micro-payoff #1
by ~2,000 — bigger question + next action
by ~5,000 — micro-payoff #2 / functional clue

No Hook Reset: no long biography after the opening promise. Context must move with action.

### MACRO SPINE
0–2% title promise/proof/first payoff
5–10% anomaly deepens / intentionality
12–18% substantial partial answer
20–30% first hidden-space/human-history reveal + pressure shadow when appropriate
35–45% direct pressure active when applicable
45–55% deeper mystery / personal reinterpretation
55–68% pressure + hard choice
68–76% final mechanism convergence
78–85% title-level grand discovery
85–92% meaning/consequence
92–100% emotional/procedural closure

After ~5,000 chars, do not plan a >~6,500-character retention desert containing only repair, travel, description or reflection.

## MYSTERY LAYERS

M0 opening anomaly
M1 primary physical mystery
M2 deeper intentional mystery
M3 human story
M4 personal connection
M5 final truth

Answering a mystery should usually create a larger question or consequence.

## CLUES

Design 8–12 useful clues. Every major clue pays off. At least two clues are reinterpreted later.
Prefer physical / architectural / mechanical / documentary / behavioral evidence over vague intuition.

## REVEAL LADDER

R1 anomaly confirmed
R2 deliberate design
R3 human story
R4 personal connection
R5 grand physical discovery
R6 true meaning
R7 present consequence

Do not dump all truth in one letter or one box.

## PRESSURE

Use a believable source: buyer/developer, family, legal/institutional, demolition, weather/structure, money, ownership, preservation.

Human antagonist can return. Each return must add information, leverage, temptation or consequence.

## WORK = STORY

Design 6–10 competence/restoration scenes.
At least two discoveries should happen because the protagonist measures, repairs, cleans, documents, tests or preserves carefully.

## 7-PART DEFAULT

1. Promise + Proof + Commitment
2. Investigation + First Deeper Payoff
3. First Opening
4. Human Truth
5. Pressure + Hard Choice
6. Grand Reveal + Consequence
7. Longer-term resolution if procedural + Healing + Legacy

Each Part needs roughly 9–14 functional beats with causality, state change and a concrete forward pull; depth must support 70k–80k without filler.

## OUTLINE QA

Before output:
- title promise fulfilled;
- one primary DNA selected;
- anomaly is physical;
- 6+ clues;
- 4+ reveal levels;
- pressure escalates;
- competence matters;
- restoration moves plot;
- protagonist has agency;
- grand reveal is more than money;
- present consequence is plausible;
- family-antagonist loop deliberately resolved if introduced;
- ending resolves wound through action;
- all major loops close;
- enough functional material for **70k–80k inclusive** without filler, while preserving protected story functions and the early retention ladder.
